Six sites. Pick one.

The same projects and bio, presented six completely different ways. Open each, play with it, and keep the one that feels like you.

  1. 01The Deck→Dark and editorial. A particle name, projects as a hand of playing cards, a mapping robot, Wordle, a GPU race and a hidden terminal.
  2. 02MatejOS→A whole fake operating system. Boot it up, drag windows around, open projects from a file explorer.
  3. 03Swiss Kinetic→Bright, precise poster design where the giant type moves with you and every project gets a generated poster.
  4. 04Galaxy→A 3D solar system where each project is a planet. Fly between them.
  5. 05Sketchbook→A hand-drawn engineering notebook with doodles that draw themselves and sticky notes you can drag.
  6. 06Arcade→A playable pixel game. Walk a little robot around and visit each project like an arcade cabinet.
All six read their content from shared/data.js, so updating your bio or projects there updates every version.
